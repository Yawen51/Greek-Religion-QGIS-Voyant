# Project Overview

This project uses QGIS and Voyant Tools to study the spatial distribution and textual representation of local and foreign religious cults in the Hellenistic to Roman Imperial period. The dataset combines spatial analysis, statistical outputs, and digital text analysis to examine patterns of religious movement, especially in relation to ports and trade networks.
